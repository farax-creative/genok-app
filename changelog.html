Changes

Newest first · Devlog

  • 0.1.1172026-10The side panel of a result is one flat sheet now: no card borders, no second title, and five keys in the shortcut bar. A long answer to a question now wraps and the box grows, so what you are typing no longer slides out of sight. Usage numbers now say "used", so it is clear they are the share spent and not the share left. Trimmed places that said the same thing twice: the version on the sitemap, the waiting hint in the inbox, and the project name on the next-result card.
  • 0.1.1162026-10Halved the empty room around the floating window. The shadow stays, and a screen capture picks up a thinner blank border. Screen descriptions are down to one sentence each: the connect intro, the first usage screen, the home activity source, and the waiting alert. Removed the sub line in the inbox info panel that repeated its title.
  • 0.1.1152026-10Fixed the search and tab strip at the top of the conversation list showing in a different colour from its panel. It now follows the panel's colour in every theme and style. Conversation rows are two lines by default again. The one-line view is still there to pick. Fixed the shortcut bar on a result riding up as you scroll. It stays at the foot. The title-bar usage keeps the ring spreading around each lamp when the numbers are shown. Pressing Start on a hidden session that was still running only said it was already on, while the list did not show it. It is now shown again. "Your turn" beside a floating chat lists that conversation's own items only. Another department's question no longer shows there, and the section is gone when there is nothing. The floating block's menu is down to five rows. The set-once options are under "More". A conversation floated from the app now comes up inside the Genok window, at its top right.
  • 0.1.1142026-10On the PC settings screen, the "AI connection" and "Allow" tabs no longer open with a heading that repeats the tab's name. A project now has a "Board" view: each result's versions run in a row with the directives applied between them. Dragged cards snap into line with their neighbours, and "Tidy" puts them all back. On a phone it opens as version rows first. Pictures pasted into a conversation in the official Claude apps now show in Genok's chat too. Hiding a row in the chat list now hides the same-titled sessions folded behind it as well; before, only the top one went and the row looked unchanged. To-dos in the inbox are split into "New" and "Reply": clear New with "Mark all read" and Reply with "All to later". The bell count drops with them. The left menu no longer unfolds the list of projects; one row leads to the project list. The chat window pinned to the taskbar is now exactly the size of the panel you see (474×687, or 794×687 when large). It used to be 1255×735, so screen captures took the empty area too. Fixed buttons in the pinned chat and the floating window closing the window instead of doing their job. The pinned chat's float button now opens the conversation as a floating window in the same place. The pinned chat's … menu has "Close when clicking outside". Off (the default) keeps it open. Fixed the right column staying empty when the chat window is set to large. The title-bar usage has "No numbers": the lamps alone, as on a phone; the card they open still has the figures. The board's toolbar is down to three icon buttons (fit, tidy, version rows). Zoom with the wheel or a pinch. In the conversation list, search, new session and the tabs stay at the top while you scroll. Rows are one line by default, and the less used view switches moved behind More. Project order is now changed by dragging on the project list screen. On a result's Questions tab, the "answered" label that wrapped under the tab is now a single check mark. The floating window and the pinned chat are put above other windows again once shown, land inside the screen on a monitor with another scale, and no longer close right after opening. A version pressed on the board or in the version rows opens as that version.
  • 0.1.1132026-10The hint line under search no longer repeats "Esc close": the Close button above already says it. (Korean only) The connection state in the title bar now uses the same word as the settings screen. On the phone and PC session lists, the "show older sessions" row starts where the session rows do. Chats the Codex app opened without a folder are filed under one "Codex" entry instead of one per folder name ("new-chat" and the like). The first-run card on home now calls Codex connected by the same rule as the title bar: signed in and answered a test turn.
  • 0.1.1122026-10On the phone tab bar, opening Chat no longer lights the All tab as well. The note above the message box of an ended session is gone: the box's own placeholder already said it. When a conversation's title is the project's name, the status line under it no longer repeats the name. The "show older sessions" row is taller on a phone, easier to press. When sessions share a name, the one the department uses keeps it and the leftover is marked "old", so the name alone says which to use. Moving a department to a new session now ends the old one even if it was waiting on a question, or as soon as it rests if it was working. Its conversation stays. "Clear older sessions with the same name" in the session list now also ends the resting ones, so the Claude app stops listing them. It used to hide them in Genok only. Settings has "Show results in the chat too": when on, a session that pushes a result to Genok also writes it out in its reply. Off by default. On the PC list screens the shortcut hint bar stays at the foot of the panel even under a short list. The settings tab "Agents" is now "AI", matching the screen it opens.
  • 0.1.1112026-10On a phone a screen's title no longer wraps into two lines: the usage pill there starts as its dots alone. In the session list, older sessions with the same name fold behind the newest one; press +N on the row to unfold them. A session's title skips opening lines such as the working-folder notice or a file list heading and shows what was first said. The card that opens from the usage pill has switches for showing the 5-hour and weekly percent, on a phone too. A Codex 5-hour window that has reset since the last use shows 0% instead of disappearing. Two sessions no longer sit under one name in the Claude app's job list: a session started or brought back in a folder that already has one is numbered, and jobs that already share a name are numbered while they rest.
  • 0.1.1102026-10A taskbar pin is now the app's own icon with a state dot at its corner (working is green), and its hover name says the state in words. The chat's memory percentage is a small ring; press it for the memory, the 5-hour and weekly limits and when they reset.
  • 0.1.1092026-10The widget, the chat it opens and a taskbar pin's chat window now have smooth corners and a soft shadow instead of a stepped edge.
  • 0.1.1082026-10The widget no longer shows a dark backing at its cards' corners, between cards, or around its menu, and an opened chat is no longer cut off at one side. Taskbar-pinned sessions wear the same state orb as the chat, still and sharp at the taskbar's size. One press hides the older sessions of a shared name, with undo. Home's to-check items are compact tiles.
  • 0.1.1072026-10Session titles show the session's name again, and a session waiting on a permission prompt no longer reads as working for hours. A newest-first switch in the session list. The widget and taskbar-pinned session windows are only as large as what they show. Home lists sessions at work as tiles.
  • 0.1.1062026-10The widget window is only as large as its blocks, which reduces the dark slab on mixed-scale monitors. The taskbar shows usage and the alert count, and sessions can be pinned as buttons. Fixed several sessions appearing under one name. The context % on session rows is off by default and turned on in Settings. Version and update check moved beside Settings.
  • 0.1.1052026-10The widget no longer sits on a dark slab and can allow or deny on its own. Chat folds work into one line and shows to-dos, per-file changes and per-turn time. Home lists the sessions waiting on you, and a row put aside to the Later tab leaves the bell count. Voice input in every text field, and phone alerts on iPhone are fixed.
  • 0.1.1042026-10Chat text reads easier: larger on phones, with more room between paragraphs and list rows. Code blocks wrap instead of sliding sideways and always show a copy button. The model picker marks the model in use instead of a separate default row. Fixed two overlaps on phones (the chat header menu button, the answer button on a result) and removed the unused ready-made answers.
  • 0.1.1032026-10While you speak, the chat box shows a listening row: stop keeps the words, send sends them at once, X discards what was just said. The mic now sits beside send, and the hint text in the box is no longer cut off on phones. On phones the model picker is a rounded sheet at the bottom of the screen.
  • 0.1.1022026-10Speak to type in the chat box, where the browser supports speech recognition.
  • 0.1.1012026-10Separate switches for what the app icon number counts (results, chats), a setting to show work steps in the chat, and distinct icons for General and Language.
  • 0.1.1002026-10Choose what the app icon number counts, see files a session sends in the chat, a quieter chat log, and a fixed header overlap on phones.
  • 0.1.992026-10Correct the packaged update feed directory; retains all 0.1.98 fixes.
  • 0.1.982026-10Interpret legacy feedback timestamps in the host PC timezone and refresh elapsed labels. Show recent feedback delivery records for the exact conversation, separately from completion. Fix a CSS collision hiding the mobile model picker and keep its sheet above the composer. Make the result header back button return directly to the results list. Match intermediate loading marks to the initial splash logo size and detail.
  • 0.1.972026-10Prevent long descriptions from overlapping settings navigation labels in medium-width touch windows. Reviewed English settings, navigation, and larger text at 320, 430, 820, and 1024px.
  • 0.1.962026-10Keep previously confirmed Codex conversations visible while the first desktop list loads after restarting Genok. Retain identifiers only, without copying titles, messages, or activity into this cache. Refresh identities from successful desktop responses and respect the read permission.
  • 0.1.952026-10Keep conversations present in the official Codex app current in project lists between turns, matching the conversation overview. Working indicators still require activity information.
  • 0.1.942026-10The guide now says clearly, in Korean and English, that adding the results tool is optional and is not needed for ordinary chat or for passing feedback on. When the tool does not show in the connection preview, the guidance is kept apart from the restart an ordinary chat may ask for.
  • 0.1.932026-10On touch screens the selected background of the results sort button no longer spills past its border. On mid-size touch screens search has its own row, and the filter, sort and view controls share one height. On the PC the gap between the selected background and the outer border is even.
  • 0.1.922026-10On a phone, a bottom sheet opened while the keyboard is already up appears above the keyboard from the start. When the keyboard leaves very little room the sheet still fits the screen and scrolls inside. The centred window on the PC and the default position after the keyboard closes are unchanged.
  • 0.1.912026-10Connection and permissions can be checked from More in a session's menu. Seeing the conversation list, passing messages on and hiding from the list are shown separately, and anything that cannot be checked is not shown as allowed. The AI's own permission to edit files and run commands is kept apart from what Genok may pass on, with a way to the connection settings when needed.
  • 0.1.902026-10Going to settings on a phone no longer shows the previous screen and the bottom menu on top of each other. The update status and its button line up, and the settings icons and touch areas were tidied. A result card shows the size of the version on screen instead of the total of all versions; the total is on the clean-up screen. Long result summaries open with More, and the version storage tools stay folded until needed. The bottom menu's selection mark and number badge are separate, and repeated motion was reduced.
  • 0.1.892026-10Pressing Claude or Codex in the usage at the top opens that service's detailed usage. A session can be pinned to the top, hidden from the list and brought back; hiding does not delete the conversation or stop it running. The feedback guidance on results follows the app's Korean or English setting, while comments and attachment paths stay as written. Keyboard selection and closing in the usage panel, and touch areas on phones, were tidied.
  • 0.1.882026-10The build stops if development documents, logs, backups or debug files would be packaged. The screens and guide files that ship are checked for private key text and source map links, and the update ZIP gets the same check.
  • 0.1.872026-10The build stops if the security scan of the app, the update ZIP or the installer fails. Before an official update goes out, file hashes and the Windows signatures of the app, the CLI and the installer are checked. Moving a conversation card no longer leaves its old border behind or shows the held card half transparent.
  • 0.1.862026-10Dragging a conversation no longer leaves a dark border where it was. The held card is opaque, set apart by a soft shadow, and returns to its place smoothly when dropped without moving. Screens showing through each other during the settings transition were reduced.
  • 0.1.722026-10Opening a result link from another app no longer asks you to register a phone that is already registered. A phone address opened on the PC goes straight to the PC screen. On the phone, the Results tab shows how many results are new.
  • 0.1.712026-10"Your turn" now shows only when a session is waiting for your approval or answer. A session that is already working shows "Working". Hidden sessions stay hidden, and the session list shows only the ones in use. You can select several sessions and drag them together. On the phone, the bottom tabs have "All" and a long press on a list card reorders it. Web addresses in a conversation open with a click, and an update shows what changed before you download it.
  • 0.1.702026-10You can add Genok to your phone's home screen and use it like an app. If the phone can't reach your PC, you get a retry button instead of a blank page. You can now search inside a conversation (Ctrl+F in the app window), a result with two versions opens side by side as soon as you press Compare, and a long press on a result card starts selecting several.
