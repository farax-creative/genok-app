Install and connect

Beta · written for 0.1.70

The app's screens are in English or Korean. A few lines may still appear in Korean.

When something doesn't work

If a blue "Windows protected your PC" window appears

The installer isn't code-signed yet, so Windows asks first. Two clicks get you past it.

  1. Click More info.
  2. Click Run anyway, which appears below.
If it says Genok couldn't be installed

Quit Genok from the tray and run the installer again. If it keeps failing, send us %LOCALAPPDATA%\Genok\install.log.

If the window stays white

Edge WebView2 is missing. Windows 11 includes it. On Windows 10, install the "WebView2 Runtime" from Microsoft.

My comment didn't reach the session

Check that you reopened the Claude Code / Codex window after connecting, and that the session is working in the same folder the result was sent from.

The link doesn't open

Check that Genok is in the tray. If another program is using port 8777, Genok picks a free one between 8778 and 8796, so opening the result from the app window is the surest way.

I want to review on my phone

Phone viewing is a Pro feature and needs a key. It isn't fully tested in the beta yet, so review on your PC for now.

Step by step

1Install
  • Run Genok_0.1.70_x64-setup.exe. It doesn't ask for administrator rights.
  • There is nothing to choose. A small window with the logo and a thin progress line shows for a moment, then Genok opens.
  • It installs to %LOCALAPPDATA%\Programs\Genok. You don't need to install Python or ffmpeg.
2First run
  • Open Genok from the Start menu or the desktop. The setup screen walks you through the steps in order.
  • Results are kept in Documents\Genok unless you pick another folder during setup.
  • Closing the window doesn't quit the app. It stays in the tray, next to the clock. To quit, click the tray icon and choose Quit.

Enter your beta key

  1. Open Settings › License and paste the whole key, then press Apply. No key yet? Press Get a key on the same screen. It asks for an email only, not a card.
  2. With a valid key, the Pro features open: viewing on your phone, more than one of your own accounts, full version history, phone notifications.
  3. If the key is rejected, read the reason shown on the screen first. If there is none, copy the whole key again and paste it once more. If that fails, write to support@genok.app.
  4. The key runs for one year from the day you get it. If you change PCs or lose the key, write to support@genok.app.
3Connect Claude Code / Codex

The Claude Code step of setup shows one of three things.

  • Claude Code is not installed: install it with the steps below, then click Check again.
  • Sign-in needed: click Sign in. A black terminal window opens with Claude Code running in it. Sign in as it asks, come back to Genok and click Check again. You can close the terminal.
  • Connected: go on to the next step. Genok adds a hook and a skill to your Claude Code settings and keeps the original as settings.json.bak-<time>.

If you don't have Claude Code

  1. Open PowerShell from the Start menu, paste this line and press Enter. You don't need administrator rights. 
    irm https://claude.ai/install.ps1 | iex
  2. When it finishes, open a new PowerShell window, run claude and sign in through the browser. You need a paid plan such as Claude Pro, Max or Team, or a Console account. The free plan doesn't work.
  3. Come back to Genok and click Check again. If it still says Claude Code is not installed, quit Genok from the tray and open it again.

Claude Code / Codex windows that were already open need to be reopened before the connection takes effect.

  • If you use Codex: after connecting, open codex in a terminal and allow the hook once under /hooks. Comments aren't delivered until you do.
  • The Claude and ChatGPT desktop apps can send results and read comments, but they don't wake a session (a Claude Code or Codex window you have open and working).
4Send a result

Ask Claude Code / Codex to "send the result to Genok". To do it yourself, use the command on the "send from a session" card in Settings.

"%LOCALAPPDATA%\Programs\Genok\_internal\loop.exe" push <file> --item <name> --note "note"
  • Send again with the same --item and the versions stack up as v002, v003, so you can compare them.
  • If the send is refused, there are comments you haven't answered. Look at them with loop.exe todo --item <name>, then send again with --fixed <id> for the ones you handled and --later <id> for the ones you put off.
  • The http://localhost:8777/i/... address you get back opens on this PC only.
5Updates
  • Under Settings › About, click Check for updates. If there is a new version, click Update. Genok downloads and installs it.
  • If it is waiting to restart, click Restart to apply when it suits you.
  • Applying an update closes the app once and opens it again. Your results, settings and chats stay.
  • If it says it failed, check your internet connection and click Try again.
  • If the app doesn't open after an update, or the version hasn't changed, download the new installer and run it over the old one. Your data and settings stay.
  • If the app doesn't come up right after an update, open Genok again from the Start menu.
6Uninstall and your data
  • Windows Settings → Apps → Genok → Uninstall. This removes the shortcuts, the install folder and the start-at-sign-in entry, and takes the hook and skill back out of Claude Code and Codex. It takes out only what Genok added, and backs each settings file up first.
  • Your results and comments are not deleted. To remove everything, delete Documents\Genok in your user folder, or the folder you picked, yourself.
Something in your way? Tell us in one line, right when it happens. In the app it's Send feedback in the title bar, or Open form under Settings › About when the window is narrow. Send feedback
Still not working after this page? Open Settings, find the diagnostics card, choose Save diagnostics bundle and send the file to support@genok.app. It contains folder paths that include your Windows user name, and your project names.
