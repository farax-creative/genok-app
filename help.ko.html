설치와 연결

베타

잘 안 될 때

파란 "Windows의 PC 보호" 창이 뜨면

아직 코드 서명 인증서가 없어서 뜨는 경고입니다. 두 번 누르면 넘어갑니다.

  1. 추가 정보를 누릅니다.
  2. 아래에 생기는 실행을 누릅니다.
"Genok을 설치하지 못했어요"가 뜨면

열려 있는 Genok을 트레이에서 종료하고 설치 파일을 다시 실행합니다. 계속 안 되면 %LOCALAPPDATA%\Genok\install.log를 보내 주세요.

창이 하얗게만 뜨면

Edge WebView2가 없는 것입니다. Windows 11에는 기본으로 들어 있고, Windows 10에서는 Microsoft에서 "WebView2 런타임"을 받아 설치합니다.

코멘트를 남겼는데 세션이 모릅니다

Claude Code / Codex 창을 연결한 뒤에 새로 열었는지, 결과물을 올린 폴더와 같은 폴더에서 일하는 세션인지 확인합니다.

주소가 안 열립니다

트레이에 Genok이 떠 있는지 확인합니다. 다른 프로그램이 8777 포트를 쓰고 있으면 Genok이 8778~8796 중 빈 포트를 고릅니다. 앱 창에서 여는 것이 가장 확실합니다.

폰에서 보고 싶습니다

폰에서 보기는 Pro 기능이라 키가 있으면 열립니다. 다만 베타에서는 아직 확인되지 않은 기능입니다. PC에서 먼저 확인해 주세요.

순서대로

1설치
  • Genok_x64-setup.exe 하나만 실행합니다. 관리자 권한은 묻지 않습니다.
  • 고를 것이 없습니다. 로고와 가는 진행선만 있는 작은 화면이 잠깐 보이고, 끝나면 Genok이 바로 켜집니다.
  • %LOCALAPPDATA%\Programs\Genok 폴더에 설치됩니다. 파이썬이나 ffmpeg를 따로 깔 필요는 없습니다.
2첫 실행
  • 시작 메뉴나 바탕화면의 Genok을 엽니다. 첫 설정 화면이 순서대로 안내합니다.
  • 결과물은 기본으로 문서\Genok에 쌓입니다. 첫 설정에서 다른 폴더로 바꿀 수 있습니다.
  • 창을 닫아도 꺼지지 않고 트레이(시계 옆)에 남습니다. 완전히 끄려면 트레이 아이콘에서 종료를 누릅니다.

베타 키 넣기

  1. 설정 › 라이선스를 열고, 받은 키를 통째로 복사해 붙여 넣은 뒤 [적용]을 누릅니다. 키가 없으면 같은 화면의 [키 받기]를 누르세요. 이메일만 넣으면 되고 카드는 묻지 않습니다.
  2. 키가 맞으면 폰에서 보기, 본인 계정 여러 개 연결, 버전 전부 보기, 폰 알림 같은 Pro 기능이 열립니다.
  3. 안 되면 화면에 나오는 이유를 먼저 보세요. 이유가 없으면 키 전체를 다시 복사해 붙여 넣으세요. 그래도 안 되면 support@genok.app으로 알려 주세요.
  4. 키는 받은 날부터 1년 동안 씁니다. PC를 바꾸거나 키를 잃어버리면 support@genok.app으로 알려 주세요.
3Claude Code / Codex 연결

첫 설정의 Claude Code 단계에는 셋 중 하나가 보입니다.

  • Claude Code가 없어요: 아래 순서대로 설치한 뒤 다시 확인을 누릅니다.
  • 로그인이 필요해요: 로그인를 누르면 검은 터미널 창이 새로 뜨고 Claude Code가 그 안에서 켜집니다. 안내대로 로그인한 뒤 Genok으로 돌아와 다시 확인을 누릅니다. 터미널 창은 닫아도 됩니다.
  • 연결됨: 그대로 다음으로 갑니다. Genok이 Claude Code 설정에 훅과 스킬을 넣고, 원래 설정은 settings.json.bak-<시각>으로 백업합니다.

Claude Code가 없을 때

  1. 시작 메뉴에서 PowerShell을 열고 아래 한 줄을 붙여 넣은 뒤 Enter를 누릅니다. 관리자 권한은 필요 없습니다. 
    irm https://claude.ai/install.ps1 | iex
  2. 끝나면 PowerShell을 새로 열어 claude를 실행하고 브라우저에서 로그인합니다. Claude Pro·Max·Team 같은 유료 플랜이나 Console 계정이 있어야 합니다. 무료 플랜으로는 안 됩니다.
  3. Genok으로 돌아와 다시 확인을 누릅니다. 그래도 "없어요"가 나오면 Genok을 트레이에서 종료했다가 다시 켭니다.

이미 열려 있던 Claude Code / Codex 창은 새로 열어야 연결이 적용됩니다.

  • Codex를 쓰면, 연결한 뒤 터미널에서 codex를 열고 /hooks에서 훅을 한 번 허락해야 코멘트가 전달됩니다.
  • Claude 데스크톱 앱과 ChatGPT 데스크톱 앱에서는 올리기와 코멘트 읽기만 됩니다. 세션(Claude Code나 Codex를 켜 둔 작업 창)을 깨워 주지는 않습니다.
4결과물 올리기

Claude Code / Codex에게 "결과물을 Genok에 올려줘"라고 하면 됩니다. 직접 하려면 설정의 "세션에서 올릴 때 쓰는 명령" 카드에 있는 명령을 씁니다.

"%LOCALAPPDATA%\Programs\Genok\_internal\loop.exe" push <파일> --item <이름> --note "메모"
  • 같은 --item으로 다시 올리면 v002, v003으로 쌓여 비교할 수 있습니다.
  • 올리기가 거절되면 답하지 않은 코멘트가 남아 있는 것입니다. loop.exe todo --item <이름>으로 확인하고, 반영한 것은 --fixed <id>, 미룬 것은 --later <id>를 붙여 다시 올립니다.
  • 올라간 뒤 나오는 http://localhost:8777/i/... 주소는 이 PC에서만 열립니다.
5업데이트
  • 설정 › 정보에서 업데이트 확인을 누릅니다. 새 버전이 있으면 업데이트를 누르세요. 내려받기와 설치까지 이어집니다.
  • 다시 켜기를 기다리고 있으면 편할 때 다시 켜서 적용을 누릅니다.
  • 적용하면 앱이 한 번 꺼졌다 켜집니다. 결과물, 설정, 대화는 그대로입니다.
  • 실패했다고 나오면 인터넷 연결을 확인하고 다시 하기를 누릅니다.
  • 업데이트 뒤 앱이 안 켜지거나 버전이 그대로면 새 설치 파일을 받아 그대로 다시 설치하세요. 데이터와 설정은 남습니다.
  • 업데이트 직후 앱이 한 번에 안 뜨면 시작 메뉴에서 Genok을 다시 엽니다.
6제거와 데이터
  • Windows 설정 → 앱 → Genok → 제거. 바로가기, 설치 폴더, 로그인 때 자동 시작이 지워지고 Claude Code와 Codex에 넣었던 연결(훅·스킬)도 같이 빠집니다. Genok이 넣은 설정만 빼내고, 빼기 전에 백업을 남깁니다.
  • 결과물과 코멘트는 지워지지 않습니다. 다 지우려면 내 사용자 폴더의 Documents\Genok(또는 직접 고른 폴더)을 따로 삭제합니다.
쓰다가 불편한 것이 있나요? 그때 바로 한 줄만 적어 주세요. 앱에서는 제목 줄의 의견 남기기, 창이 좁으면 설정 › 정보의 양식 열기입니다. 의견 남기기
이 페이지대로 해도 안 되나요? 설정의 "문제 진단" 카드에서 진단 묶음 저장으로 만든 파일을 support@genok.app으로 보내 주세요. 이 파일에는 Windows 사용자 이름이 든 폴더 경로와 프로젝트 이름이 들어 있습니다.
