FAQ

자주 묻는 질문

Claude Code와 Codex 둘 다 되나요?
네. 둘 다 연결해 한 화면에서 봅니다. 세션이 loop push로 결과물을 올리고, 남긴 코멘트를 다음 턴에 받아 갑니다.
API 키가 필요한가요? 추가 비용이 드나요?
아니요. 지금 쓰는 구독 계정으로 로그인하고, 별도 API 키는 필요 없습니다. Genok이 따로 과금하지도 않습니다. 세션이 일한 만큼은 쓰시는 Claude Code / Codex 사용량에서 나갑니다.
데이터는 어디에 있나요?
문서\Genok 폴더에 프로젝트와 버전별로 쌓입니다. 결과물은 이 폴더로 복사돼 보관되고, 탐색기로 열어 볼 수 있습니다.
인터넷에 공개되나요?
아니요. 서버는 127.0.0.1에서만 열립니다. 폰으로 볼 때도 나만 접속할 수 있는 연결로만 열립니다.
Windows에서 SmartScreen 경고가 떠요
설치 파일에 아직 코드 서명이 없어서, Windows가 처음 보는 앱을 실행하기 전에 확인 창을 띄웁니다. 추가 정보를 누른 뒤 실행을 누르면 설치가 진행됩니다.
