Article 1. Purpose and Scope

These Terms set out the conditions for using the desktop application Genok (the "App") and the related website, both provided by Calars (the "Company") under the brand name Farax Creative. By downloading and installing the App, or by using it, you are deemed to have agreed to these Terms.

Article 2. The Service

Genok is a Windows app that collects the images, videos, documents, and code output produced by coding sessions such as Claude Code and Codex into versions on the user's PC, lets the user view them, mark them up on screen and leave comments, and delivers those comments to the session.

  • The App runs on the user's PC. By default its internal server listens only on this PC (127.0.0.1). If you turn on phone viewing, it also listens on your own Tailscale private network. There is no separate Company server or account.
  • The App passes your comments to the session and, when needed, wakes the session on your PC so that it continues. The work is done by your own Claude Code / Codex session. The Company charges no AI usage fee of its own and uses no separate API key. Work a session does counts against your own Claude Code / Codex usage.
  • The App does not read, copy, or send out the login (OAuth) tokens of Claude Code or Codex. It refers to their settings only to identify which account a session should be started with.
  • Output and comments are stored in the Documents\Genok folder on the user's PC.

Article 3. Fees and Plans

The App can be used for free through one full loop (collecting output, comparing versions, commenting, delivering to the session). To lift the limits and add features, use a paid plan.

  • Pro: US$9 per month or US$79 per year. Full version history visible, viewing on a phone (your own Tailscale), connecting more than one of your own accounts.
  • Lifetime: US$149, one-time payment. You keep using the Pro features, and updates released while we run Genok are included. Sold in a fixed number of seats.
